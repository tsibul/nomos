# Акты ЕС по НДС и VIES: источник EUR-Lex / CELLAR и план сборки

Дата проверки: 2026-11-21. Метки: **[П]** — подтверждено запросом в этой сессии (адрес указан);
**[?]** — не подтверждено, открытый вопрос. Дополняет `vat-sources.md` (раздел 1) и исправляет
его там, где проверка дала другой результат (отмечено «поправка»).

Акты: Директива 2006/112/EC (`eu/dir/2006/112`), Имплементационный регламент (ЕС) 282/2011
(`eu/reg_impl/2011/282`), Регламент (ЕС) 904/2010 (`eu/reg/2010/904`).

## 1. Выводы

1. Источник — **Formex 4 сводных редакций из CELLAR**, не HTML EUR-Lex: в Formex есть номера
   положений (`ARTICLE IDENTIFIER="098A"`, `PARAG IDENTIFIER="098.002"`), период действия
   редакции и метки изменений с точным положением изменяющего акта. В HTML адреса есть только
   у статей, разделов и приложений.
2. Formex есть у всех трёх актов и у сводных, и у текстов OJ, на en и el; русского нет **[П]**.
3. Сводные редакции с 01.01.2024 есть по датам; редакция на дату — наибольшая дата ≤ нужной.
4. Сводные тексты — документальные, без юридической силы; аутентичен только OJ. Отражается в
   источнике (`Source` `eurlex`), статус выражения — как у CyLaw (см. 5.3).
5. Условия: сводные тексты и редакционное содержание EUR-Lex — CC BY 4.0 (указать источник и
   изменения); акты — свободное повторное использование по решению 2011/833/EU **[П]**.
6. Автоматический доступ: `eur-lex.europa.eu` — `Crawl-delay: 10`; `publications.europa.eu` —
   `Allow: /`. Явных лимитов частоты CELLAR не найдено **[?]**. Сборка — 20–30 файлов, пауза 10 с.
7. Модели нужна одна правка: вид фрагмента «подсекция» (`sbs`) — в директиве 12 подсекций.
   Остальное — правки кода загрузчика, не модели и не формата (раздел 6).

### 2.3. Устройство Formex сводной редакции **[П]**

- Корень `CONS.ACT`; `INFO.CONSLEG` — `START.DATE` (начало редакции), `END.DATE`
  (`99999999` — открыта; иначе день перед следующей), `SOURCE.END` (CELEX акта, которым она
  кончается). Пример 282/2011: `START.DATE="20250414" END.DATE="20280630"
  SOURCE.END="32025R0518"`.
- Структура: `DIVISION` с `TITLE/TI` («TITLE I», «CHAPTER 1», «Section 1», «Subsection 1»,
  «Section 2a»), `ARTICLE IDENTIFIER="098A"` + `TI.ART`, `PARAG IDENTIFIER="098.002"` +
  `NO.PARAG`, `ALINEA` (абзац без номера), `LIST TYPE="alpha|roman|ARAB|DASH"` → `ITEM/NP`
  + `NO.P` + `TXT`, `CONS.ANNEX` (приложение; внутри `CONTENTS`, части «PART A»), `TBL`,
  `NOTE` (сноски), `DATE ISO=…`, `QUOT.START/END`, `HT TYPE="BOLD|ITALIC"`.
- Метки изменений — инструкции обработки, парами открыть/закрыть:

  ```
  <?CLG.MDFO ID="O026001M003000" IDREF="C026001M003000" ACTION="REPLACED"
    LEVEL="STRUCTURE" COMMAND="EXPLICIT" ACTIVE.DOC="32022L0542" ACTIVE.LOC="AR:1;PT:6"
    MOD.LEVEL="1"?>
  <ARTICLE IDENTIFIER="098">…</ARTICLE>
  <?CLG.MDFC ID="C026001M003000" IDREF="O026001M003000"?>
  ```

  `ACTION` — INSERTED / REPLACED / DELETED; `ACTIVE.DOC` — CELEX изменяющего акта (у
  исправлений — `32017R2454R(01)`); `ACTIVE.LOC` — положение: `AR:1;PT:6` = ст. 1 п. (6)
  (= `art_1.pnt_6` из примера 7.1 модели); бывают составные (`AR:1;PT:23 .AND. AX:0;PT:1`).
- Преамбулы в сводных нет: `PREAMBLE` пустой, соображений (`CONSID`) 0 у всех трёх актов.
  Соображения есть только в тексте OJ.
- Греческий Formex 282/2011 совпадает с английским по всем `IDENTIFIER` и `ACTIVE.LOC`
  (разница — порядок двух меток) **[П]**.

### 2.4. HTML EUR-Lex (запасной путь) **[П]**

`id` есть у статей (`art_98`, `art_98a`), разделов (`tis_IV.cpt_1.sct_2.sbs_1`) и приложений

## 4. Статус и условия

- Каждая сводная редакция начинается оговоркой: текст — «meant purely as a documentation tool
  and has no legal effect»; аутентичны акты в OJ **[П]** (шапка HTML `02006L0112-20250414`).
  Правовое уведомление EUR-Lex: аутентичны только документы OJ, правила — Регламент Совета
  (ЕС) 216/2013 **[П]** (`https://eur-lex.europa.eu/content/legal-notice/legal-notice.html`).
- Повторное использование (то же уведомление) **[П]**: политика Комиссии основана на решении
  2011/833/EU; юридические документы EUR-Lex можно использовать в коммерческих и некоммерческих
  целях, если не оговорено иное (исключение — например, МСФО); редакционное содержание,
  резюме и **сводные тексты** — CC BY 4.0: указать источник и отметить изменения.
- Решение 2011/833/EU (`http://publications.europa.eu/resource/celex/32011D0833`) **[П]**:
  ст. 6 — документы доступны без заявки; условия могут включать указание источника, запрет
  искажать смысл, отказ Комиссии от ответственности; ст. 8 — обязанности переводить нет.
- Для МСФО (позже): уведомление прямо называет их исключением с особыми условиями.

## 5. План

### 5.1. Порядок актов

1. **904/2010** — первым (предлагается, вопрос 1): мал (83 статьи, 15,8 тыс. слов), три
   редакции с 2024 — проверяет и базу, и смену редакций; VIES — цель пилота.
2. **2006/112** — основной объём (496 статей, 5 редакций), на него ссылаются кипрский закон и
   282/2011.
3. **282/2011** — две редакции; ссылки в основном на директиву, поэтому после неё.

### 5.2. Сборка

Новый сборщик `collect_eurlex` (пакет `src/nomos/sources/eurlex/`), по образцу `collect_cylaw`:

1. Манифест `Nomos-texts/<uid>/collect.xml`: CELEX акта, список сводных редакций (от
   действующей на 01.01.2024), изменяющие акты с датами (публикация OJ, вступление в силу,
   ручные уточнения дат по положениям), ручные решения.
2. Исходники (zip Formex en/el) — в `Nomos-texts/sources/eu/…`, скачиваются отдельной командой
   или вручную; сборщик сеть не трогает. Пауза между запросами — 10 с.
3. Разбор каждой редакции в дерево по `eid` (5.4). Опорный язык — en; el вешается на те же
   фрагменты по `IDENTIFIER` и порядку; расхождение — в отчёт.
4. Базовые редакции — по сводной, действующей на 01.01.2024. Далее для каждой следующей
   сводной: фрагменты с изменившимся нормализованным текстом, новые и исчезнувшие получают
   редакцию `key = START.DATE`, `applies-from = START.DATE`; изменение — по ближайшей
   охватывающей метке `CLG.MDFO` этой сводной (`ACTIVE.DOC` → акт, `ACTIVE.LOC` → `provision`,
   `ACTION` → `kind`). Исчезнувший фрагмент — `state="repealed"`. Метка на статье целиком
   (`REPLACED`, `LEVEL="STRUCTURE"`) — новые редакции у статьи и всех потомков (правило 1.8).
5. `valid-from` — дата вступления в силу из манифеста; `known-from` — дата публикации
   изменяющего акта в OJ.
6. Каждый изменяющий акт с 2024 — свой каталог и `act.xml` (`relation kind="amends"`,
   `amendment` по положениям), фрагменты — из его Formex OJ (`3{год}{L|R}{номер}`), чтобы
   `amending_fragment` находился; тексты en/el — по решению (вопрос 3).
7. Отчёт: метки без пары, составные `ACTIVE.LOC`, изменения текста без метки, расхождения
   en/el.

Сравнение сводных, а не применение формулировок изменяющих актов — как решено в модели (8).

### 5.3. Источник и статус

- `Source` `eurlex`: имя «EUR-Lex — сводная редакция (документальная, не аутентичная)»,
  publisher «Publications Office of the EU», license `CC BY 4.0`, terms_url — правовое
  уведомление, attribution «© European Union, https://eur-lex.europa.eu; сводная редакция
  без юридической силы; аутентичен текст в OJ».
- Выражения en, el: `status="official_text"`, `source="eurlex"` — так же, как сводная CyLaw
  (`official_text` + источник с пометкой «неофициальная»). Отдельного статуса не нужно.
- Для изменяющих актов, взятых из OJ, — тот же `eurlex` или отдельный `eu-oj` (вопрос 5).

### 5.4. Структура → `eid`

| Formex | kind | eid (пример) |
|---|---|---|
| DIVISION «TITLE IV» / «CHAPTER 2» / «Section 2a» / «Subsection 1» | `tis` / `cpt` / `sct` / `sbs` | `tis_IV.cpt_2.sct_2a.sbs_1` (как `id` HTML EUR-Lex) |
| ARTICLE `IDENTIFIER="098A"` | `art` | `art_98a` (номер как напечатан, строчная буква) |
| PARAG `098.002` | `par` | `art_98.par_2` |
| ALINEA (если в родителе их больше одного или рядом список) | `sub` | `art_98.par_2.sub_2` |
| ITEM `(a)` / `(i)` / `(1)` | `pnt` | `art_98.par_2.pnt_a`, `…pnt_a.pnt_i`, `anx_III.pnt_10c` |
| ITEM в `LIST TYPE="DASH"` | `ind` | `…ind_1` |
| CONS.ANNEX «ANNEX III», «PART A» | `anx`, `prt` | `anx_III`, `anx_VIII.prt_A` |
| TBL | `tbl` | `anx_X.tbl_1` |
| NOTE | — | `<fn>` в тексте |
| преамбула OJ (вопрос 6) | `cit`, `rct` | `cit_1`, `rct_12` |

Единственный ALINEA статьи или пункта — текст самого фрагмента, без `sub`. Заголовок статьи
(`STI.ART`) — `heading`, `TI.ART` — `num`.

### 5.5. Ссылки

- Внутри акта ЕС — правила разметки для английского (`refs.EN` рядом с `refs.EL`): «Article

## 6. Изменения, требующие утверждения

Модель (`docs/design/data-model.md`, код `acts/models`):

1. `Fragment.Kind` — добавить `sbs` («Подсекция»): 12 подсекций в директиве, так их называет
   EUR-Lex. Миграция — только список выбора.

Код загрузчика (поведение модели не меняется, но решение пользователя нужно для п. c):

- a. `load_texts.SOURCES` — добавить `eurlex` (без него `Expression.source` пуст и загрузка
  падает: поле обязательное).
- b. `load_texts` читает из `act.xml` атрибуты `celex`, `eli`, `date-adopted` — поля в модели
  есть, загрузчик их не читает. Формат 3.3 их не перечисляет — дополнение формата.
- c. `load_texts` читает `marker` у `<amendment>` (поле `Amendment.marker` есть) — для меток
  `M32`. Атрибут есть в формате 3.3, загрузчик его пропускает.
