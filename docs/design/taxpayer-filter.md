# Фильтр «физлица / ИП / юрлица»

Статус: утверждено пользователем (вопрос 193). Кода и моделей нет. Поле `who` внесено в
`docs/design/data-model.md`.

## 1. Круг лиц

| Код | На сайте | Кто входит |
|---|---|---|
| `ind` | Физлица | физическое лицо как таковое: работник, пенсионер, владелец имущества |
| `se` | ИП | физлицо, ведущее деятельность само (самозанятый, αυτοτελώς εργαζόμενος) |
| `co` | Юрлица | компании и прочие организации: товарищества, фонды, трасты, филиалы |

Отдельного статуса ИП на Кипре нет, поэтому `se` — самозанятое физлицо. Положение о «лице»,
«налогоплательщике», «облагаемом лице» без уточнения касается всех трёх.

## 2. Пометка `who`

### 2.1. Значение

- `who` — набор кодов через пробел: `who="ind se"`.
- `who="all"` — касается всех. Это значение по умолчанию.
- Пометка не зависит от языка. Переводы её не меняют.

### 2.2. Где хранится

В `act.xml` — источнике истины. В БД это только копия, пересобираемая при загрузке.

```xml
<act uid="cy/law/2002/118_I" ... who="all">

  <fragment uid="…" kind="art" eid="art_8" who="ind se">
    <version key="base" … />
  </fragment>

  <fragment uid="…" kind="par" eid="art_8.par_21A" who="ind">
    <version key="base" … />
  </fragment>

  <fragment uid="…" kind="art" eid="art_9" who="co" who-by="auto">
    <version key="base" … />
    <version key="2025-12-22" … who="co se" />
  </fragment>
```

- У акта — значение по умолчанию для всего акта. Закон о подоходном налоге — `all`, будущий
  закон о спецвзносе компаний — `co`.
- У фрагмента — круг лиц положения.
- У редакции — только если изменение расширило или сузило круг лиц. Тогда эта редакция
  и следующие берут значение редакции, а прежние — фрагмента.
- `who-by` — откуда пометка: `auto` (поставлена сессией по смыслу, не проверена) или
  `manual` (проверена). Без атрибута — `manual`.

### 2.3. Наследование

- Фрагмент без `who` берёт значение ближайшего предка, у которого оно есть, затем — акта,
  затем — `all`.
- Пометка у потомка заменяет унаследованную, а не складывается с ней. Пункт статьи
  `ind se` может быть `ind`; может быть и шире статьи, если так в тексте.
- Определения, ячейки таблиц, сноски наследуют, как все.
- При загрузке для каждой редакции вычисляется итоговое значение `who_eff` и хранится в БД.

### 2.4. Положения для всех

- Общие положения (определения, сроки, санкции, обжалование) — `all`, обычно по
  наследованию от акта, без пометки.
- Если статья касается одного круга, а пункт внутри нее — всех, у пункта ставится
  `who="all"` явно.

## 3. Откуда берётся пометка

Пометка ставится по смыслу положения: кому оно адресовано — кого обязывает, кому даёт право
или льготу, чей доход или сделку описывает. Слова текста — подсказка, а не правило:
`φυσικό πρόσωπο` в определении или в оговорке «кроме физических лиц» не делает положение
положением для физлиц.

1. Автопометка. Сессия Claude Code при разметке акта читает статью целиком и ставит `who`
   по смыслу с `who-by="auto"`. Пометка ставится только там, где круг лиц отличается от
   унаследованного. Модель — Sonnet, сомнительные случаи — Opus. Сомнение записывается
   примечанием `kind="doubt"` к фрагменту.
2. Проверка. При проверке разметки пометка подтверждается или исправляется, `who-by="auto"`
   снимается.
3. Пока `auto` не снято, у пометки на странице знак «не проверено». Фильтр её учитывает.

Скриптов, ставящих пометку по словам, нет. Действует только то, что записано в `act.xml`,
поэтому ручная правка не теряется при пересборке.

Справочные материалы (`Material`) получают такой же атрибут `who`. По умолчанию его берут от
привязанного акта.

## 4. Фильтр на странице акта

- Переключатель «Все · Физлица · ИП · Юрлица» стоит на странице текста акта, над текстом.
  Можно выбрать несколько. На прочих страницах (список актов, общий поиск, раздел
  справочных материалов) фильтра нет.
- Адрес: `?who=ind` или `?who=ind,se` у адреса акта или его статьи. Без параметра — все.
- Переходы внутри того же акта (оглавление, ссылки на его статьи, смена даты и языка)
  параметр сохраняют; ссылки на другие акты — нет. Cookie не нужна: выбор принадлежит
  странице, и «открыть в отдельном окне» даёт ту же картину по адресу.
- Положение показывается, если в его `who_eff` есть хоть один выбранный код или `all`.
- Скрытое положение не исчезает бесследно, чтобы не путать нумерацию: на его месте —
  строка «скрыто: п. 3–5 (юрлица)», по нажатию раскрывается.
- Предок показан всегда, если показан хоть один его потомок. Если сам предок не подходит,
  от него остаются номер и заголовок, без текста.
- Каждому показанному положению — значок круга лиц (`ind`, `se`, `co`), если не `all`.
- Блок «Справочные материалы» на странице акта фильтруется тем же выбором по `who`
  материала.
- Фильтр работает вместе с `@дата`, `?known=` и выбором языка.

## 5. Отвергнутые варианты

- Пометка только в БД — пропадёт при пересборке; источник истины — XML.
- Отдельный файл пометок рядом с `act.xml` — пометка оторвана от фрагмента и сломается при
  перенумерации; в `act.xml` она привязана к `uid`.
- Пометка механически по словам текста — признак в одном пункте неверно переносится на всю
  статью, а исключения («кроме компаний») не ловятся. Решение пользователя: по смыслу.
- Переключатель на весь сайт с выбором в cookie — решение пользователя: переключатель на
  странице текста акта.
- Скрывать положения целиком — теряется нумерация и контекст статьи.
- Складывать пометку потомка с пометкой предка — тогда нельзя сузить круг лиц для пункта.
